MUSIC:
The first site's files did not include an audio file, so this project includes a music button that is ready for a local file.
To add your music:
1. Put your MP3 in this folder.
2. Rename it to: music.mp3
3. Upload music.mp3 to the same GitHub repository as index.html.

Then the ♫ button at the bottom-right will play/pause it after the browser allows playback.
